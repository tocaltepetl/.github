# Cómo cuidamos tu privacidad

Aplica a todos los proyectos de [tocaltepetl](https://github.com/tocaltepetl).
Si un proyecto hace algo distinto, lo dice en su README.

## Lo que no hacemos
- No pedimos cuenta, nombre, correo ni teléfono para usar las páginas.
- No usamos cookies de seguimiento, publicidad ni rastreadores.
- Tu ubicación, si una página la usa, se queda en tu navegador: no se envía ni
  se guarda.

## Conteo de visitas
Para saber cuánta gente usa cada página contamos visitas con
[Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/): sin
cookies ni datos personales, sin seguir a nadie entre sitios. Solo vemos
totales (visitas, páginas, país, navegador) y tiempos de carga.

## Reportes anónimos
Cuando una página permite reportar (p. ej. «no pasó el camión», «no me
funciona»):
- Solo se aceptan opciones de una lista cerrada, sin texto libre.
- No se guarda tu IP ni ningún identificador; la IP solo se usa en memoria
  para limitar abusos.
- Los conteos se publican agregados y solo a partir de un mínimo de reportes,
  para que nadie pueda identificarse.

## Lo que se publica en GitHub
Las solicitudes o reportes con detalle se publican como issues públicos. No
incluyas datos personales, CURP, RFC, folios de trámites personales ni
contraseñas. Los folios de solicitudes de transparencia sí pueden publicarse:
ya son públicos en la Plataforma Nacional de Transparencia (ver
[solicitudes](solicitudes/README.md)).

## No somos gobierno
Los proyectos son ciudadanos y **no oficiales**. No representan a ninguna
dependencia.

¿Dudas? Abre un issue en el repo del proyecto.
